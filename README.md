# [에움길 API](http://aeum-gil.com)

## 환경

- Node.js `v20.12.0`
- PostgreSQL (Supabase)

## 로컬 실행

- `src/config/local.env` 참조
- `/files/presigned-url` API를 로컬에서 사용하려면 AWS 키 설정 필요
- `yarn start:dev` 실행
- `http://localhost:3000`으로 API 호출

## 데이터베이스 설정

Supabase의 Session Pooler 또는 Direct Connection 정보를 사용합니다.

```env
POSTGRES_HOST=...
POSTGRES_PORT=5432
POSTGRES_USERNAME=...
POSTGRES_PASSWORD=...
POSTGRES_DATABASE=postgres
```

실제 시각은 `timestamptz`, JSON 데이터는 `jsonb`를 사용합니다.

## DDL

각 블록의 `CREATE TABLE`을 먼저 모두 실행한 뒤, 블록 안의 `ALTER TABLE`과 인덱스를 실행합니다. `chapter`와 `page`는 서로 참조하는 순환 외래 키이므로 테이블 생성 전에 추가할 수 없습니다.

    <summary>chapter</summary>

```sql
CREATE TABLE chapter (
    id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title varchar(200) NOT NULL,
    image varchar(400) NOT NULL,
    first_page_id integer,
    created_at timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP
);

ALTER TABLE chapter ADD CONSTRAINT chapter_first_page_id_fk
    FOREIGN KEY (first_page_id) REFERENCES page(id);
```
